# DaVinci 网关路由工具 1.3.6

本版做两件事：桌面端界面**只保留双栏布局**（移除原版单栏长条对比模式），并修复 Bridge 鉴权拒绝时的一个真实缺陷。

**路由规则、输入契约、ARXML 处理逻辑与公共接口均未改变。**

## 一、界面只保留双栏布局

- **移除布局切换**：顶栏的「双栏布局 / 单栏布局」按钮删除，界面不再提供原版单栏长条的对比形态。顶栏右侧现在只有「重置演示数据」（开发环境下有示例输入时才显示）与主题切换。
- **移除原版模式代码**：单栏长条布局容器、原版模式红色提示条与布局堆叠一并删除，代码中不再有第二套布局分支，卡片始终挂载在左侧输入侧栏与右侧校验工作台。
- **文档同步**：`docs/GUI.md` 中「与原版布局的对比」一节改为「单一双栏布局」，明确界面只有一种形态。

## 二、Bridge 鉴权拒绝的连接中断修复

**问题现象**：向 Bridge 内部端口发送不带令牌或令牌错误的请求时，客户端有时拿到的是连接错误（Windows `WinError 10053`），而不是预期的 401。

**根因**：鉴权中间件在拒绝请求时直接返回 401 响应，没有先读完请求体。客户端此时还在发送 body，服务端就关闭连接，Windows 网络栈用 RST 中断连接，调用方收到的是传输层错误而不是 HTTP 状态码。该问题在 1.3.5 的干净代码上同样可复现，与界面改动无关。

**修复**：拒绝路径在回 401 之前先排空请求体（上限 1 MiB，避免异常客户端无限占用内存），保证响应能被客户端完整读取。鉴权语义不变：无令牌与错误令牌依然返回 401，合法令牌照常通过。

**回归覆盖**：新增单元测试锁定「拒绝前必须读完请求体」这一行为；修复后全量测试连续三次稳定通过。

## 验证

全量测试 **432 通过 / 10 跳过**（跳过项需要真实输入文件、PowerShell 7 或已构建产物）。界面侧用真实文件（`AX-网关配置_v4.83-4.85.xlsx` + `RoBoTaxi.arxml`）驱动渲染，逐轮核对白天与夜间两套主题，确认移除对比模式后双栏布局完好。

版本标签为 `v1.3.6`。GUI、MCP、核心及 Windows 版本资源统一为 1.3.6，构建脚本默认版本同步更新。Release 提供 GUI 与 MCP 的 Windows x64 ZIP 及对应 `.sha256` 校验文件；安装包从干净提交构建（`BUILD_INFO.json` 中 `dirty=false`），归档哈希与校验文件逐位匹配。
