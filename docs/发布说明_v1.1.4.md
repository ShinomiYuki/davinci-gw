# DaVinci 网关路由工具 1.1.4

修复新增 CAN 诊断路由与既有 PduR 目标容器符号名冲突的问题。优先沿用 `Diag_TP_<CAN ID>_<目标网段>`；名称被占用时，使用包含源、目标网段的 `GWT_Diag_TP_<CAN ID>_<源网段>_To_<目标网段>`，避免不同来源汇聚到同一目标时重名。

同一 `TRANSPORT_PROTOCOL` 路径新增多个目标时，共用该路径的 Queue；已有路径优先复用既有 Queue，保持其参数。独立新路径的队列配置规则不变。

输出的共享 Queue 校验仅针对 `TRANSPORT_PROTOCOL`。普通 `COMMUNICATION_INTERFACE` 整帧转发增加目标腿时，不再被 TP 队列规则误拦截；对象语义、内部引用、Handle ID 与路由组成员校验继续保留。

GUI、MCP 与 Windows 版本资源同步升级为 1.1.4。
