## 直接报文 ADD

一条源端路由链由 EcuC 源 PDU、CanIf Rx、PduR RoutingPath 和唯一 SrcPdu 组成；每个目标腿新增 EcuC 目标 PDU、CanIf Tx 和 PduR DestPdu。相同源报文、源 CAN ID 和源通道会合并为一个 RoutingPath，多目标只追加 Destination。

依赖顺序固定为 EcuC → CanIf Rx/Tx → PduR Path/Src/Dest。HRH 和 TxBuffer 由“引用数据”精确映射并在当前文件内唯一解析。报文类型、DLC Check、Truncation 和 Length Strategy 使用集中映射，不做模糊匹配。

## 信号路由 ADD 与超时

工具通过 ComIPdu 的信号引用精确确认源/目标 ComSignal 属于预期报文和方向，再生成一个 ComGwMapping、一个 Source 和一个或多个 Destination。已有同源 Mapping 时只补缺少的 Destination；完全一致时幂等跳过。

“超时时间”被视为上游已经标准化的输入，直接写入源 ComSignal，不从报文或其他字段反推 Cycle Time。测试明确覆盖标准值 `2`（100 ms 边界对应 2000 ms）和 `4`（大于 100 ms 对应 4000 ms）。超时替代值和超时时间为空时不写零，也不新增对应参数。LIN 信号路由只引用已有 Com 对象，不创建 LinIf。

## 命名、UUID 与 Handle ID

- EcuC/CanIf PDU：`GWT_{报文}_{去CAN后通道}_{Rx|Tx}`。
- PduR Path：`GWT_{源报文}_{源CANID大写十六进制}_{去CAN后源通道}`；Src/Dest 使用不带 `GWT_` 的路由腿名称。
- Com Mapping：`GWT_Sig_{源信号}_{源网段}`；Source/Destination 分别使用 `ComGwSource_...`、`ComGwDestination_...`。
- UUID 使用固定命名空间的 UUID5，输入为对象路径、克隆节点序号和节点类型。同一输入可复现，且预检保证不占用任何既有 UUID。
- Handle ID 不沿用旧工具固定值 `1`。对 CanIf Rx、CanIf Tx、PduR Src、PduR Dest 四个参数定义分别收集已使用整数，按稳定计划顺序分配最小未占用非负值。

真实基线本身含有历史重复 Handle 和 7 组历史重复 UUID。本轮不修改无关对象，因此差异化验证允许这些历史问题保持原样，但要求所有本次新增 Handle 均未在基线占用、所有本次新增 UUID 在输出中全局唯一。旧工具仅用于确认历史命名和链路意图；其字符串模板、固定 UUID 递增和固定 Handle `1` 均未复用。

## 幂等、冲突与缺失对象

幂等比较包含定义、全部相关参数和引用，不以全局 SHORT-NAME 唯一为前提。完全一致返回已有并跳过；同路径不同定义/参数/引用、部分直接报文链、已有 Mapping Source 不兼容、Destination 同名异引用、超时冲突、计划路径/UUID 冲突均阻止输出。

真实项目可能尚未导入目标版本 DBC。源/目标 ComSignal、ComIPdu、HRH 或 TxBuffer 等单条 ADD 依赖缺失时，生成器返回带 Excel 行号、对象和处理建议的 WARNING，跳过受影响路由并继续其他有效 ADD。候选不唯一、已有对象语义冲突、DELETE、结构错误和输出复核错误仍是全局阻断错误。

## 错误处理矩阵

| 场景 | 行为 |
|---|---|
| 配置表含 DELETE | 阻止正式生成，退出码 2 |
| 单条 ADD 缺少 DBC/HRH/TxBuffer | 警告并逐路由跳过，继续其他 ADD |
| 候选不唯一或同名语义不同 | 阻止生成，列出工作表行号和对象上下文 |
| 模板、父容器或内部引用无法安全确定 | 阻止生成，不修改输入、不写目标 |
| 已有配置完全一致 | 幂等跳过 |
| 输出已存在或等于基准 | 默认阻止 |
| 临时输出复核失败 | 删除临时文件，不留下目标或半成品 |
| 文件损坏或 I/O 失败 | 结构化系统错误，退出码 3 |

## 代码审查发现与修复

审查真实输入时发现两类不应由新增工具误报的历史数据：Handle ID 在真实定义作用域内已有重复值，基线也有 7 组重复 UUID。已将策略从“历史数据必须全局唯一”修正为“新增值不得复用任何既有值，输出只验证本次新增唯一性”，既不掩盖新增冲突，也不修改无关基线。

性能审查发现四个模块编辑器重复构建 81 MB 全树索引，以及输出复核重复扫描模板。已改为共享单次基线索引、计划阶段保存预期 UUID、Handle 单次统计，避免不必要的全树遍历。

同时补充了历史重复 UUID 容忍、新增 UUID 唯一、已有 Mapping 只补 Destination、输出复核失败清理临时文件等回归测试。

最终审查还发现 ComIPdu 在只有一个同报文候选时曾未强制核对网段，以及超时参数模板理论上可能携带 UUID。已改为报文、方向、网段同时精确匹配，并对超时参数克隆执行同样的 UUID5 重建和计划冲突检查；另增加 Excel 路由行反序后输出字节一致的确定性测试。
