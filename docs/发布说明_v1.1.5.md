# DaVinci 网关路由工具 1.1.5

CAN 诊断新增路由与既有 DoIP 路由引用同一目标 EcuC PDU 时，现在共用同一 Queue。此前只检查单条路径内的多个目标，会为跨路径共享目标另建队列，导致 DaVinci 报 PDUR13205。

队列选择沿完整目标 PDU 引用追踪直接和间接关联的传输协议路径。优先复用唯一既有队列，保留 Depth、TpThreshold 和缓冲池引用；既有队列冲突时报告路径并停止，不擅自改写基线。同批新增路径共用队列，新队列取关联路由所需的较大 Depth，7DF 或功能寻址为 5，普通为 3，TpThreshold=0。普通整帧转发不适用该检查。删除 CAN 路由时保留仍被其他路径使用的队列和端点。

增加根目录 `AGENTS.md` 和统一 `setup.ps1` 安装入口。AI 读取入口后可以直接查看安装计划、下载对应版本的免 Python 包、完成客户端配置并验证 MCP 初始化、工具发现和版本，不需要逐篇搜索安装文档。支持 Codex 和 DSH Desktop；DSH 使用 `cordis.patch.yml` 中的 `mcp-client` 插件，保留其他配置并在修改前备份。源码模式使用工程内虚拟环境，不修改系统 Python。

DSH 配置格式已依据 DSH Desktop 0.9.1 搭载的 Harness 0.1.5-rc.2 实现核对。客户端重新加载后仍须调用能力查询确认会话接入；脚本不强制关闭或重启客户端。

核心、GUI、MCP 和 Windows 版本资源统一为 1.1.5。发布包含 Windows x64 GUI、MCP ZIP 及校验文件。客户工作簿和 ARXML 不进入公开仓库或发布包。
