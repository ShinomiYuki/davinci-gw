# DaVinci 网关路由工具 1.3.1

本版重做桌面端界面，并新增白天与夜间双主题。**路由规则、输入契约、ARXML 处理逻辑与公共接口均未改变**，界面只是换了一种呈现方式。

界面从原来的平铺分组改为「页头 + 步骤卡片」结构：页头显示标题、一行说明、主题切换、版本号与「本地运行」标识；工作流拆成「① 选择输入文件」和「② 预览并生成」两张卡片，步骤用序号徽标标出；状态条按流程状态着色（进行中蓝、通过绿、需处理橙、失败红），进度条只在预览或生成期间出现；生成结果、输入检查、变更摘要与问题清单各自成卡片，问题表按级别着色并可按级别筛选与全文搜索，暂无问题时显示空状态说明。

新增白天 / 夜间两套主题：页头可一键切换且即时生效，无需重启；首次启动跟随 Windows 的应用主题，用户手动切换后写入当前用户设置，下次启动沿用。夜间主题同步调整 `QPalette`，使下拉框、滚动条、对话框和悬浮提示等原生绘制部分一并换色；两种主题共用同一套布局与信息层级，状态色语义保持一致。

界面版本号改为读取 `UI.__version__`，不再在窗口代码中硬编码；窗口位置、主题等设置统一走 `QSettings`，入口未设置组织名时窗口会兜底设置，保证设置始终可写。变更详情弹窗的关闭按钮文案改为中文。

本版同时包含 1.3.0 引入的本地 Bridge 服务：在内部端口上提供 MCP 端点，把请求转发到可独立配置的核心。Bridge 只做令牌校验与转发，默认只监听回环地址，不开放自动修复与诊断工具，目前只提供源码运行入口，尚未纳入免安装包。

版本标签为 `v1.3.1`。GUI、MCP、核心及 Windows 版本资源统一为 1.3.1，GitHub Release 提供 GUI、MCP Windows x64 ZIP 和对应校验文件。公司镜像同步提交和标签，二进制以 GitHub Release 为准。

文档同步更新到当前实际状态：README 补充 Bridge 与新界面说明，GUI 使用说明增加界面与主题章节，MCP 与安装文档的版本示例对齐 1.3.1，架构评估报告增加实施进展。

验证使用人工构造的工作簿和 ARXML，覆盖生成策略、空白与旧表、路由复用、删除、参数清理、无路由保护和共享冲突；界面侧覆盖主题切换即时换肤、状态条随流程状态变化与问题级别配色。未修改客户配置，也未执行 DaVinci 的实际 Validate/Generate。
