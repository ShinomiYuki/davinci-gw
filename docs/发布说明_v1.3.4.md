# DaVinci 网关路由工具 1.3.4

本版重做桌面端界面骨架：窗口从「居中卡片流」改为**应用壳层**结构。**路由规则、输入契约、ARXML 处理逻辑与公共接口均未改变**，只调整界面组织与视觉表达。

## 界面结构

- **顶部全宽导航栏**：左侧是矢量网关拓扑标识与标题、版本号、「本地运行」标识，右侧是布局对比开关与白天 / 夜间主题切换（按钮改为「浅色 / 深色」并带太阳 / 月亮矢量图标）。顶栏不再随内容滚动。
- **左侧输入侧栏**：固定宽度 470 像素，独立滚动，容纳「选择输入文件」「预览并生成」「生成结果」三张卡片。
- **右侧校验工作台**：细网格背景，容纳状态条、「问题与保留决定」「输入检查」「变更摘要」。
- **底部全宽状态条**：操作 ID、会话 ID、版本与日志目录入口，固定在窗口底部。
- **状态条改为步骤面包屑**：右侧依次显示「1. 选择文件 / 2. 预览校验 / 3. 确认生成」，当前步骤高亮，并保留 `STEP n / 3` 徽标。

## 视觉细节

- **矢量图标**：`QPainter` 绘制，不依赖外部图片资源。新增品牌拓扑标识、表格 / ARXML 文档图标、说明框信息图标、筛选级别圆点与太阳 / 月亮主题图标；「预览变更」「生成 ARXML」「选择输出」「打开所在文件夹」按钮按主题配色挂图标。
- **问题表自绘**：改用自定义委托渲染，每行呈现「确认复选框 + 彩色级别胶囊 → 等宽规则代码与报文名副行 → 粗体问题描述与柔和工程建议副行 → ARXML 节点位置 → 确认状态胶囊」。原「报文 ID」「报文名称」「处理建议」三列并入副行，不再单列展示，表格因此能在一屏内呈现完整工作上下文。
- **确认状态可视化**：右侧一列用胶囊区分「○ 待确认」「✓ 已确认」「✕ 需修复」，左侧级别胶囊按错误 / 警告 / 保留决定 / 提示分色。
- **文件槽区分类型**：配置表用绿色系、基准 ARXML 用蓝色系，输入契约说明改为带信息图标的说明框。
- **双主题一致性**：白天与夜间两套主题下卡片、表格、胶囊、图标与状态色语义保持一致，夜间只降低亮度，不改变信息层级。

## 顺带修正

- 切换到「原版单栏长条」对比模式时，空的「生成结果」「输入检查」「变更摘要」卡片与残留进度条不再被重新显示。
- 问题表高度随可见条数自适应，首屏不再只露出两三行。

## 验证

全量测试 431 通过、10 跳过（跳过项需要真实输入文件、PowerShell 7 或已构建产物）。新增回归覆盖自绘委托与折叠列、切换布局后空卡片保持隐藏。界面侧用真实文件（`AX-网关配置_v4.83-4.85.xlsx` + `RoBoTaxi.arxml`）驱动渲染，逐轮核对白天与夜间两套主题，以及原版单栏对比模式。

## 版本

版本标签为 `v1.3.4`。GUI、MCP、核心及 Windows 版本资源统一为 1.3.4。本版包含 1.3.3 的全部缺陷修复。Release 提供 GUI 与 MCP 的 Windows x64 ZIP 及对应 `.sha256` 校验文件；安装包从干净提交构建（`BUILD_INFO.json` 中 `dirty=false`），归档哈希与校验文件逐位匹配。
