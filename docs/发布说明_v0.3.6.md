# DaVinci 网关路由工具 v0.3.6

本版本修复 E03 BEV/REEV 配置中缺失 DBC 信号删除、专项路由组冲突和既有源 Rx 类型差异导致的误阻断。

## 用户可见变化

- DELETE 信号的 DBC 端点和相关 Mapping 都已不存在时，按“无需再删除”跳过；若仍有悬空 Mapping 引用则继续阻断。
- 同一 CAN 通道存在正式应用组和测试/专项组时，工具在真实引用结构基础上交叉确认唯一 `<通道>App` 组，专项组不会接收普通新增路由。
- 新增目标报文时，如果完整既有源 Rx 的 CAN 类型与配置表默认值不同，使用基准 ARXML 的类型并保持源 Rx 不变。
- DELETE 的源类型校验仍然严格，其他身份冲突、非法类型和组歧义不会被放宽。
- GUI 对上述非操作性提示明确显示“无需处理”，不再要求用户修改配置表。
