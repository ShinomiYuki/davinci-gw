# DaVinci 网关路由工具 v0.3.5

本版本修复应用路由组中存在完整非 CanIf 目标成员时，整个应用组被误判失效的问题。

## 用户可见变化

- 应用组中的 Com、CanTp、DoIP 等完整目标成员不再导致同组 CanIf 成员整体失效。
- 一个路由组的问题只影响相关目标通道，不再阻断所有 ADD。
- 基线问题只显示基准 ARXML 位置，不再错误挂到当前 Excel 行和计划 DestPdu。
- 相同基线问题在 ADD、DELETE 和两阶段事务中只显示一次。
- GUI 会明确提示非 CanIf 成员已从普通 CAN 通道统计排除，无需删除配置表需求。
- 继续保留悬空、重复、主通道歧义、实际组不一致等安全阻断。

## 版本

- GUI/Core：0.3.5
- MCP：0.2.5
