# DaVinci 网关路由工具 1.3.2

本版按新的界面稿重做桌面端布局。**路由规则、输入契约、ARXML 处理逻辑与公共接口均未改变**，只调整呈现方式与交互密度。

窗口改为「页头 + 双栏工作台」：整体宽度上限 1380 像素并居中，左栏约五分之一宽度用于输入与执行，右栏用于状态与校验工作台，右侧首屏即可看到完整的问题清单。文件输入从「标签 + 超宽输入框 + 浏览 + 清除」改为紧凑文件槽：图标、标题、后缀、状态徽标、路径与操作按钮都在一行内，可直接拖入文件。

问题区改为带实时计数的级别胶囊（全部 / 错误 / 警告 / 提示 / 保留决定），搜索框收敛为固定宽度并与「复制所选」「批量确认」并列。警告与保留决定新增「确认」列，可逐条勾选或一次性批量确认，状态条会提示还有多少项待确认；双击问题行可打开详情窗口查看文件、工作表、行号、字段、关联报文与处理建议。底部原先的大块元数据卡片收敛为一行等宽字体信息条。

页头新增布局对比开关，可在「双栏紧凑布局」与「原版单栏长条布局」之间实时切换，便于对照查看输入框与搜索框被拉长后的差别，切到原版布局时给出红色提示条并可一键切回。开发环境下存在示例输入时，还会显示「一键填入测试数据并预览」。

配色对齐新的界面稿：浅色使用 `#F1F5F9` 画布与 `#2563eb` 品牌蓝，夜间使用 `#0B1120` 画布与 `#0F172A` 卡片，两套主题的信息层级与状态色语义保持一致。

本版同时包含 1.3.0 引入的本地 Bridge 服务与 1.3.1 的双主题能力。

版本标签为 `v1.3.2`。GUI、MCP、核心及 Windows 版本资源统一为 1.3.2，GitHub Release 提供 GUI、MCP Windows x64 ZIP 和对应校验文件。公司镜像同步提交和标签，二进制以 GitHub Release 为准。

验证使用人工构造的工作簿和 ARXML，覆盖生成策略、空白与旧表、路由复用、删除、参数清理、无路由保护和共享冲突；界面侧新增布局切换、人工确认与筛选计数测试，并逐轮核对浅色与夜间两套主题的渲染效果。未修改客户配置，也未执行 DaVinci 的实际 Validate/Generate。
