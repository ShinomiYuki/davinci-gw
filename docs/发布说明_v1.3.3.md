# DaVinci 网关路由工具 1.3.3

本版修复桌面端与本地 Bridge 的五个缺陷，并用真实客户文件（`AX-网关配置_v4.83-4.85.xlsx` + `RoBoTaxi.arxml`）跑通「校验 → 预览 → 生成」全链路。**路由规则、ARXML 处理逻辑与公共接口未改变。**

## 修复

- **Bridge 默认连接失败（令牌不一致）**：访问令牌原先是每次读取都重新生成的随机值，导致客户端发现文件里的令牌与服务端鉴权用的令牌不是同一个值，调用一律 401。令牌改为在进程启动时确定一次并在整个生命周期内保持不变，发现文件与鉴权使用同一个值。
- **人工确认可被绕过**：警告与保留决定的待确认数量原先只用于显示，「生成 ARXML」按钮和 `Ctrl+G` 快捷键都能直接触发生成。待确认数量现在是唯一门禁来源，未确认完之前按钮保持禁用、按钮下方给出橙色提示、`Ctrl+G` 同样被拦截；确认后立即恢复。
- **首次并发调用裸报失败**：多个请求同时到达时，只有第一个会建立核心会话，其余请求直接被判为「核心会话不可用」。现在并发首调共享同一次建连，其余请求等待就绪信号后继续。
- **`--core-timeout` 未生效**：该参数原先只做取值校验，从未作用于实际调用。现在超时对内嵌、STDIO 与 HTTP 三种核心都真实生效，超时按核心不可用处理并写入受控日志。
- **拖入路径输入框无效**：文件槽内层输入框自己接收拖放，但其信号没有接线，拖到输入框没有任何反应。现在拖到文件槽或直接拖到路径输入框都会自动填入并识别类型。

## 顺带修正

- **版本区间命名可用**：客户常见的 `*_v4.83-4.85.xlsx` 命名原先被判定为「无法识别目标版本」并直接报错。现在按区间上限（4.85）作为目标版本，并在问题清单中给出需要人工确认的 `WORKBOOK_VERSION_RANGE` 提示；如与本次目标版本不符，仍应改用 `*_vX.x.xlsx` 命名。
- **基准路径为空不再崩溃**：预览结束时若基准路径缺失，建议输出路径的计算会抛出异常并中断界面事件处理。现在该情形直接跳过建议。
- **禁用态主按钮更明确**：「生成 ARXML」被门禁禁用时改用中性禁用配色，原先的浅蓝底白字对比度偏低。

## 验证

全量测试 429 通过、10 跳过（跳过项需要真实输入文件、PowerShell 7 或已构建产物）。新增回归覆盖：令牌在进程内保持一致、鉴权中间件只放行发现文件中的令牌、并发首调共享一次会话、核心调用超时生效、待确认时按钮与快捷键双双被拦截、拖入内层输入框能填入路径、版本区间文件名按上限解析。

真实文件验证：`AX-网关配置_v4.83-4.85.xlsx` 与 `RoBoTaxi.arxml`（85 MB）经 Bridge 校验通过，预览产出 `preparation_id` 与 8 条警告（其中 5 条为 `PDUR_ROUTING_GROUP_NON_MAIN_MEMBER` 基线一致性提示、1 条 `DIRECT_DELETE_NOT_FOUND`、1 条 `DIAGNOSTIC_LEGACY_SHEET_IGNORED`、1 条 `WORKBOOK_VERSION_RANGE`），逐项确认后生成 88 MB 新 ARXML 成功。并发首调三个请求同时返回成功，未携带令牌的请求被 401 拒绝。客户文件只做只读校验与生成，未回写原文件。

## 版本

版本标签为 `v1.3.3`。GUI、MCP、核心及 Windows 版本资源统一为 1.3.3。本版的缺陷修复随 1.3.4 一并发布，二进制以 v1.3.4 的 Release 为准。
