# 第06轮开发日志：Windows 桌面 GUI 产品化

## 目标与范围

本轮基于既有 `GatewayFacade`、公共 DTO、进度观察者、取消令牌和 Prepared Session，交付面向非开发用户的 PySide6 Qt Widgets 单窗口桌面应用。GUI 只负责编排和展示，没有新增路由业务规则，没有改变 CLI/MCP 核心工作流，也没有加入网络、遥测、自动更新或安装程序。版本提升为 0.3.0。

## 架构与状态

界面层位于 `src/UI`，调用方向固定为 `MainWindow/Widgets → GatewayViewModel → QtTaskRunner → GatewayFacade`。`QtTaskRunner` 只维护一个长驻 `QThread`；`GatewayFacade` 在工作线程中创建、持有和释放，同一时刻只允许一个重任务。每次任务使用独立线程安全 `CancellationToken`，主线程直接调用 `cancel()`，未使用 `QThread.terminate()`。

状态机明确区分 `EMPTY`、`READY`、`PREPARING`、`PREVIEW_VALID`、`PREVIEW_INVALID`、`GENERATING`、`SUCCESS`、`FAILED`、`CANCELLED`。按钮启用状态只由 ViewModel 的状态快照决定。输入路径变化会立即清空本地 Session、摘要和问题，并在工作线程异步释放旧 Prepared Session。

预览直接调用 `GatewayFacade.preview()`，成功后保留一次性 Prepared Session；生成只调用 `commit_prepared()`。输出路径默认从基准生成 `_new.arxml`，预览识别目标版本后更新为 `_v<version>.arxml`；用户手工编辑后不再自动改写。建议路径会避开已有文件，提交始终 `overwrite=False`，输出不得与基准相同。

## 界面能力

- 浏览和拖放配置表/基准 ARXML，使用同一 ViewModel 输入入口。
- QSettings 只保存最近浏览目录和可选窗口几何，不保存 Session 或输入内容。
- 动态遍历 `FeatureSummaryDto` 构建统计卡片；虚拟诊断功能测试可生成第三类卡片，无固定功能 ID 分支。
- 通过通用 `CheckResultDto(check_id, display_name, status, detail)` 展示 Schema 和模块检查，没有为四模块新增固定布尔字段。
- 问题表使用 `QAbstractTableModel + QSortFilterProxyModel`，支持错误、警告、提示、保留决定筛选、全文搜索、排序和复制。
- 问题表新增源/目标“报文 ID”和“报文名称”列；信息由已解析工作簿及问题来源行投影，不重新解析输入，也不猜测项目特定 LIN/CAN 映射。信号路由表没有 CAN ID 字段时只显示报文名称。
- 核心已有 `RetentionDecision` 以非阻塞 `DECISION` 投影到问题表，不再只显示计数。
- 动态摘要卡片在存在实际变更时显示“查看详情”，以独立非模态窗口列出实际计划新增/删除的报文或信号路由；已存在、未找到和跳过项不计入。
- 生成结果提供路径复制和打开目录；高级信息展示操作 ID、Session ID、版本和日志入口。
- 浅色界面、系统字体、标准图标、键盘快捷键和可访问名称；内容放在滚动区以适应 1366×768。
- 运行日志为 `%LOCALAPPDATA%\DaVinciGW\logs\gui.log`，1 MB 轮转、3 个备份，不记录用户内容或完整问题。

## 发布和许可证

`packaging/davinci-gw-gui.spec` 生成无控制台 one-folder Windows x64 应用；`scripts/build_gui_release.ps1` 组装免安装目录、ZIP、版本、EXE/ZIP SHA-256、MIT License、GUI 说明和第三方许可证。项目根目录 `LICENSE` 为 MIT License。

PySide6 固定在 6.8 系列；开发机最初安装的 6.11.2 无法加载 QtCore，切换到 6.8.3 后通过导入和 Qt 启动检查。第三方清单记录 Python、PySide6/Shiboken6、Qt、openpyxl、et_xmlfile、lxml、PyInstaller 和随运行库进入包内的 OpenSSL；GNU LGPL 3.0 与 lxml 6.1.2 许可证合集从官方来源拉取，OpenSSL 原文来自当前 Conda 官方包，其他原文在构建时从本次官方 wheel/运行环境复制。正式发布仍需公司合规或法务确认。

## 已知边界

GUI 不重复实现 Excel/ARXML 规则，所有业务结果以 Facade 公共 DTO 为准。协作式取消只在核心安全检查点生效；大文件序列化期间不会强制中断线程。真正无 Python 的裸机或 Windows Sandbox 证据仅在主机具备该环境时记录，不能用清空环境变量夸大为物理隔离。
