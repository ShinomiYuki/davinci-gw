# DaVinci 网关路由工具 v0.3.4

本版本修复旧名称既有直接报文路由被重复生成的问题，并保留 v0.3.3 的 Signal Access 与基线路由组警告修正。

主要变化：

- 直接报文 ADD/DELETE 统一按 CanIf、EcuC、PduR 和 RoutingGroup 的真实引用链定位，不再依赖 `Gw`、`GWT`、`GWH` 等名称前缀。
- 完整既有路由识别为 EXISTING；源链或目标端可安全复用时只创建缺失路由腿。
- 本地自发 Tx、部分链、重复完整链和错误路由组归属采用阻断式处理，不猜测、不自动清理。
- DELETE 继续限定在精确源 RoutingPath 内，不会删除路径外同名自发报文，并支持 DestPdu 使用任意合法名称。
- 新增信号路由会把实际源 Rx、目标 Tx Signal Access 设置为 `ACCESS_NEEDED_BY_SWC_OR_COM`。
- 路由组非主通道成员按基线异常去重显示，不再重复挂到每条 Excel 路由。

版本：

- GUI/Core：0.3.4
- MCP：0.2.4

发布资产包含 Windows x64 GUI 与 MCP ZIP；各 ZIP 旁提供 SHA-256 文件，包内同时包含版本、许可证和校验清单。
