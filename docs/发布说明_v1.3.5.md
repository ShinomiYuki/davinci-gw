# DaVinci 网关路由工具 1.3.5

本版按参考设计稿继续打磨桌面端界面：问题表的描述与建议改为完整换行显示，工具栏标签、状态提示与位置信息同步收敛。**路由规则、输入契约、ARXML 处理逻辑与公共接口均未改变**，只调整界面呈现。

## 问题表排版

- **描述与建议完整换行**：问题描述（粗体）最多显示两行，工程建议（灰色）最多显示三行，超出部分以省略号收尾；此前描述被单行省略号截断，长句读不全。
- **行高与文字基线重排**：行高由 92 提升到 108 像素，描述区与建议区各自独立占位，两段文字不再互相压字。
- **换行按字符宽度实测**：逐字符按当前字体度量宽度折行，中英文混排都不会溢出版心。
- **位置列只显示文件名**：原先直接铺开整条本机绝对路径，占满三行；现在只显示文件名，完整路径仍可在双击详情弹窗中查看。

## 工具栏与标签

- **「复制所选」改为浅色文字按钮**：与参考稿一致，不再与主按钮抢视觉权重；没有选中行时自动置灰。
- **「批量确认」按状态启用**：所有警告与保留决定都已确认后置灰，避免误点重复确认。
- **搜索框加宽到 288 像素**并补齐放大镜图标与省略号占位文案，容纳更长的检索提示。
- **顶栏分隔线位置调整**：「重置演示数据」与主题切换之间加入分隔线；演示按钮改用闪电矢量图标。
- **卡片说明标签统一为带图标胶囊**：如「支持拖入文件」使用带上传图标的浅灰胶囊，右侧纯文字说明仍保留文字样式，两者层级分明。

## 状态与提示

- **变更统计卡片**：移入左栏底部，标题为「本次路由变更统计」，校验通过时在右侧显示绿色「校验通过」胶囊。
- **状态条文案明确化**：全部确认后提示「所有校验项已确认，可生成 ARXML」，并给出「点击左侧『生成 ARXML』输出最终工程文件」的下一步指引。
- **底部版本信息补 AUTOSAR 版本**：显示为「版本 1.3.5（AUTOSAR R4.2.2）」。

## 验证

全量测试 431 通过、10 跳过（跳过项需要真实输入文件、PowerShell 7 或已构建产物）。界面侧用真实文件（`AX-网关配置_v4.83-4.85.xlsx` + `RoBoTaxi.arxml`）驱动渲染，逐轮核对白天与夜间两套主题，以及原版单栏对比模式。

## 版本

版本标签为 `v1.3.5`。GUI、MCP、核心及 Windows 版本资源统一为 1.3.5，构建脚本默认版本同步更新。Release 提供 GUI 与 MCP 的 Windows x64 ZIP 及对应 `.sha256` 校验文件；安装包从干净提交构建（`BUILD_INFO.json` 中 `dirty=false`），归档哈希与校验文件逐位匹配。
